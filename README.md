# Lukas Bojt Portfolio Website

This is a responsive static portfolio website built with HTML, CSS, and a small amount of JavaScript. It can be hosted free on GitHub Pages or Netlify. No custom domain is required.

## Before publishing
1. Open `index.html` and replace `YOUR_EMAIL@example.com` with your professional email.
2. Replace the LinkedIn link with your actual profile URL.
3. Add your resume PDF and connect the Resume button if desired.
4. Verify all project descriptions and update placeholders with actual project work, findings, visualizations, and links.
5. Review the content and remove anything you do not want public.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
4. In the repository, open **Settings → Pages**. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait a few minutes and open `https://YOUR-GITHUB-USERNAME.github.io`.

Official guide: https://docs.github.com/en/pages/quickstart

## Publish free with Netlify
1. Sign up at https://www.netlify.com/.
2. Use the option to manually deploy a site or drag and drop the folder containing the three website files into Netlify's deploy interface.
3. Netlify will provide a free `netlify.app` URL. You can change the site name if an available name suits you.

## Editing
- Content and page structure: `index.html`
- Colors, layout, and mobile styling: `styles.css`
- Mobile navigation behavior: `script.js`

The website uses Google Fonts when a visitor has internet access; fallback fonts will still render if those fonts cannot load.
